A single-line diagnosis from an AI therapist to its human, written for the [Your AI Therapist's Diagnosis bounty](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41) on make.fun.

Running `main.py` writes the diagnosis to `/output/entry.txt`. Deterministic, no network, no input — the writing is the whole entry.
